가계부엉은 사용자의 개인정보를 수집하지 않습니다. 계정이 없고, 앱을 만든 사람이 운영하는 서버도 없습니다. 적으신 가계부는 사용하시는 기기와 사용자 본인의 아이클라우드에만 남습니다.

1. 수집하지 않는 것

이 앱은 다음을 일절 수집하지 않습니다.

  • 이름·이메일·전화번호 등 신원 정보 (회원가입과 로그인 자체가 없습니다)
  • 위치 정보
  • 연락처·카메라·마이크
  • 사진 보관함 (캡처에서 거래를 읽는 기능이 있지만, 사용자가 그 자리에서 고른 사진 한 장만 건네받습니다 — §5)
  • 사용 기록·분석 정보 (분석 도구나 광고 모듈이 들어 있지 않습니다)
  • 기기 식별자·광고 식별자

앱은 어떤 시스템 권한도 요청하지 않습니다. 실행 중에 권한을 묻는 창이 뜨지 않습니다. 사진을 고르는 화면도 iOS 가 앱 바깥에서 띄우는 것이라(PhotosPicker) 「사진 접근을 허용하시겠습니까」를 묻지 않습니다. 물을 권한 자체를 쓰지 않기 때문입니다.

2. 어디에 저장되는가

적으신 것은 아래 두 곳에만 있습니다. 둘 다 사용자의 자리이며, 앱을 만든 사람은 어느 쪽도 들여다볼 수 없습니다.

무엇어디에
거래 내역 (날짜·금액·내용·결제수단·카테고리·메모·세금 표시)기기 안 앱 저장소, 그리고 아이클라우드에 로그인돼 있으면 사용자 본인의 비공개 아이클라우드 데이터베이스
계좌 (이름·은행·종류·처음 잔액)위와 같음
카드 (이름·카드사·종류·사용자가 적어 넣은 끝 네 자리)위와 같음
부채 (이름·은행·금액)위와 같음
카테고리·예산·자동이체 설정위와 같음
「클로드 연동」 스위치, 첫 실행을 마쳤다는 표시, 받은편지함에서 이미 본 항목의 표시기기 안 앱 설정 저장소에만. 다른 기기로 건너가지 않습니다

몇 가지를 분명히 적어 둡니다.

  1. 은행·카드사에 연결하지 않습니다. 금융기관 아이디·비밀번호·인증서·카드 번호 전체를 요구하지도, 저장하지도 않습니다. 자료는 사용자가 손으로 적어 넣은 것뿐입니다.
  2. 카드의 끝 네 자리는 카드를 구별하기 위해 사용자가 원하실 때만 적는 칸입니다. 비워 두셔도 앱은 그대로 동작하며, 앱은 그 숫자로 아무것도 하지 않습니다.
  3. 아이클라우드는 선택입니다. 아이클라우드에 로그인돼 있지 않아도 앱은 기기 안에서 전부 동작합니다. 설정 화면에 「iCloud 꺼짐」이라고 표시될 뿐 막히는 기능이 없습니다.
  4. 아이클라우드로 오가는 자료는 애플의 비공개 데이터베이스에 들어갑니다. 사용자 본인의 계정 안이며, 앱을 만든 사람에게는 열람 권한이 없습니다.

3. 개발자가 운영하는 서버가 없습니다

이 앱에는 앱을 만든 사람이 운영하는 서버가 없습니다. 사용자의 자료가 개발자에게 전달되는 경로 자체가 존재하지 않습니다.

만든 이야기가 아니라 코드에서 확인한 사실입니다. 앱의 소스 전체에서 네트워크 통신에 쓰이는 코드를 찾아본 결과가 한 건도 없습니다. 앱이 쓰는 틀은 애플이 만든 것뿐이며 (SwiftUI·SwiftData·CloudKit·Swift Charts), 다른 회사의 라이브러리가 하나도 들어 있지 않습니다.

기기 밖으로 나가는 경로는 아래 다섯이 전부이고, 다섯 다 사용자 본인의 애플 계정 안에서 끝납니다.

경로무엇이 오가나누가 볼 수 있나
아이클라우드 동기화가계부 자료 전체사용자 본인만 (애플의 비공개 데이터베이스)
아이클라우드 드라이브의 「부엉」 폴더「클로드 연동」을 켰을 때의 inbox.json 파일 하나 (§4)사용자 본인만

같은 폴더의 captures/「캡처 넣는 방법」을 맥의 클로드에 보내기로 고르셨을 때 사용자가 보낸 캡처 이미지 (§5)사용자 본인만
백업 내보내기사용자가 그 자리에서 고른 위치에 저장되는 JSON 파일 하나사용자가 정하는 대로

4. 「클로드 연동」 — 기본은 꺼져 있습니다

클로드 데스크탑 앱을 쓰시는 분을 위한 편의 기능입니다. 설정에서 직접 켜지 않으시면 앱은 어떤 파일도 열지 않습니다.

켜면 앱은 자기 자신의 아이클라우드 드라이브 폴더(파인더와 파일 앱에 「부엉」으로 보입니다) 안의 inbox.json 파일 하나만 지켜봅니다.

  • 읽는 것은 그 파일 하나뿐입니다. 기기의 다른 파일·사진·문서를 훑지 않습니다.
  • 그 파일에는 사용자 본인의 클로드가 사용자 본인의 카드·통장 캡처에서 뽑아 적어 둔 거래 줄이 들어 있습니다. 파일을 거기에 놓는 것은 사용자의 클로드이지 이 앱이 아닙니다.
  • 앱은 그 줄을 목록으로 보여 주고, 사용자가 고른 것만 가계부에 넣은 뒤 파일을 비웁니다.
  • 이 기능에도 네트워크 코드가 없습니다. 개발자의 서버도, 제3자의 서버도 거치지 않습니다. 전부 애플의 아이클라우드 드라이브 안에서, 사용자 본인 계정 안에서만 오갑니다.
  • 그 파일에 계좌 잔액과 넣은 돈(원금)이 함께 적혀 오면, 맥의 앱이 해당 계좌 값을 확인 없이 맞춥니다. 아이폰·아이패드는 이 값을 건드리지 않습니다(동기화가 늦은 기기가 옛 자료로 계산해 값을 틀지 않게).
  • 맥에서만, 같은 폴더에 가계부 사본 state.json 을 둡니다. 사용자 본인의 클로드가 가계부를 읽을 수 있게 하려는 것입니다(앱의 저장소는 macOS 가 다른 프로그램에게 열어 주지 않습니다). 사본에는 거래·계좌·카드·예산이 들어 있고, 사본을 만든 시각과 맥의 이름이 적힙니다. 앱을 켤 때, 창을 벗어날 때, 받은편지함을 반영한 뒤, 그리고 켜 둔 동안 10분마다 새로 씁니다(내용이 같으면 안 씁니다).
  • 스위치를 끄면 앱은 그 파일을 다시 읽지 않고, 맥에서는 사본 state.json 을 지웁니다.

정확히 적어 둡니다. 그 파일은 「이 기기 밖으로 나가지 않는다」가 아닙니다. 아이클라우드 드라이브에 있으므로 애플을 거쳐 사용자 본인의 다른 기기로 건너갑니다. 나가지 않는 것은 개발자에게로입니다.

5. 캡처에서 거래 읽기 — 두 길, 설정에서 고릅니다

카드·통장 캡처를 거래로 바꾸는 기능입니다. 설정 → 「캡처 넣는 방법」에서 둘 가운데 하나를 고르십니다. 어느 쪽이든 사진은 사용자가 그 자리에서 고른 것만 앱에 들어오고, 카메라는 쓰지 않습니다.

두 길의 차이는 사진이 어디까지 가는가입니다. 이 한 가지가 다르니 고르시기 전에 읽어 주십시오.

고른 길사진이 가는 데개발자에게 오나
이 기기에서 글자 읽기 (기본값)아무 데도 가지 않습니다. 기기 안에서 글자만 읽고, 사진을 복사하거나 저장하지 않습니다아니요
맥의 클로드에 보내기사용자 본인의 아이클라우드 드라이브 「부엉」 폴더 안 captures/ 에 사진 파일이 올라갑니다아니요
  • 이 기기에서 글자 읽기 — 애플이 기기 안에 넣어 둔 글자 인식(Vision)으로 읽습니다. 인터넷을 쓰지 않습니다. 읽어 낸 것은 화면에 후보로 뜰 뿐이고, 사용자가 체크한 줄만 가계부에 들어갑니다. 분류·결제수단 추천은 사용자 본인의 지난 거래를 보고 만든 것이며, 기기 밖의 어떤 모델도 쓰지 않습니다.
  • 맥의 클로드에 보내기 — 사진을 §4 와 같은 아이클라우드 드라이브 폴더에 놓아 두면, 맥에서 사용자 본인의 클로드가 그것을 읽어 거래로 만들어 inbox.json 으로 돌려줍니다. 사진이 아이클라우드에 올라간다는 뜻입니다 — 애플을 거쳐 사용자 본인의 다른 기기로 건너갑니다. 나가지 않는 것은 개발자에게로입니다. 올린 캡처는 앱 화면에서 왼쪽으로 밀어 지우실 수 있고, 파일 앱에서 직접 지우셔도 됩니다.
  • 인공지능에 사진을 건네는 것은 뒤엣길뿐이고, 그마저 사용자 본인이 자기 맥에서 부르는 클로드입니다. 앱 자신이 인공지능 서비스에 접속하는 코드는 없습니다(§3).

6. 백업 가져오기와 내보내기

  • 가져오기는 사용자가 그 자리에서 고른 파일 하나만 읽습니다. 기기의 다른 파일에는 접근하지 않습니다.
  • 내보내기는 사용자가 누르셨을 때 가계부 전체를 JSON 파일 하나로 만들어, 사용자가 고른 위치에 저장합니다.
  • 내보낸 파일은 암호가 걸려 있지 않은 보통의 텍스트 파일입니다. 가계부 전체가 그대로 들어 있으니 두시는 자리를 정하실 때 참고하십시오.

7. 제3자 제공·광고·추적

  • 앱을 만든 사람은 어떤 자료도 제3자에게 제공하거나 판매하지 않습니다. 수집하는 자료 자체가 없기 때문입니다.
  • 앱에 광고가 없습니다. 분석 도구도, 다른 회사의 SDK 도 들어 있지 않습니다.
  • 사용자를 추적하지 않으며, 다른 회사의 앱이나 웹사이트에서의 활동과 연결하지 않습니다.
  • 앱 안에서 파는 것이 없습니다.

8. 자료를 지우는 방법

앱 안에서

  • 거래·계좌·카드·부채·카테고리는 각각의 화면에서 하나씩 지울 수 있습니다.
  • 첫 실행 때 「샘플로 시작」을 고르셨다면 설정의 「샘플 데이터 지우기」로 예시 자료만 한 번에 지웁니다.

기기에서

앱을 삭제하면 기기 안에 있던 가계부와 앱 설정이 함께 지워집니다.

아이클라우드에서

⚠️ 앱을 지워도 아이클라우드에 올라간 사본은 남습니다. 함께 지우시려면 아래를 따로 하셔야 합니다.

  1. 가계부 자료 — 아이폰·아이패드에서 설정 → (맨 위 사용자 이름) → iCloud → 계정 저장 공간 관리 → 「부엉」 → 데이터 삭제. 맥에서는 시스템 설정 → (사용자 이름) → iCloud → 저장 공간 관리의 같은 자리입니다.
  2. 「클로드 연동」이 쓰던 inbox.json 과 맥에 보낸 캡처(captures/) — 파일 앱(맥에서는 파인더) → iCloud Drive → 「부엉」 폴더를 지우시면 둘 다 함께 없어집니다. 캡처만 지우시려면 그 폴더 안의 captures/ 만 지우십시오.
  3. 내보내 두신 백업 파일은 저장하신 자리에 그대로 남습니다. 필요 없어지면 직접 지우십시오.

운영체제 판에 따라 설정 메뉴의 이름이 조금 다를 수 있습니다. 「iCloud → 저장 공간 관리」 아래 앱 목록에서 「부엉」을 찾으시면 됩니다.
